# ScanIt

**Scan it before you send it.** A free, read-only Solana memecoin scanner.

Live: [scanit.lol](https://scanit.lol)

## What it does

Paste a contract address and in seconds you get:

- **A plain verdict** — Looks good, Be careful, or Stay away, with the reasons in plain English.
- **Who really holds it** — top holders with pools, exchanges and burns stripped out, so you see the real float.
- **How those wallets behave** — every holder read across its whole trading history and tagged: diamond hand, holder, serial jeet, bot, launch sniper. Not just who holds the coin, but who these people actually are.
- **Linked wallets** — farms, bundles and shared funders grouped as one operator.
- **Launch and dev record** — first buyers, bundle checks, and whether the dev has sold.
- **Real volume** — fake, wash-traded volume flagged.

Read-only. No wallet connect. Holds no keys.

## Stack

Next.js, TypeScript, Tailwind. Deployed on Vercel.
